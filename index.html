Football Match Video Analysis

I ran the detection model across full match footage to make an annotated video that marks the ball and the goalpost through every frame.

Overview

This project takes the object-detection model I trained and applies it to a full match instead of single frames. I run the footage through the model frame by frame, and for each frame it marks the ball and the goalpost with a bounding box and a confidence score, then writes it all back out as an annotated clip.

The point was to see how the model holds up on real, moving footage, where there is motion blur, changing camera angles, and players getting in the way. It also gives me a base to grow toward tracking players and detecting shots on goal.

Use cases

  • Reviewing match footage automatically instead of by hand
  • Tracking where the ball is in relation to the goal
  • A starting point for player tracking and shot detection

Smart Fridge Checkout System

A computer-vision system for an autonomous smart fridge. Cameras inside the unit detect every product a customer takes and build a live, itemized bill in real time, with no scanning or cashier needed.

Overview

This is a computer-vision system for an autonomous smart fridge, the kind of unattended unit where a customer opens the door, takes what they want, and leaves. Cameras inside the fridge watch the shelves, and the model detects each product as it is picked up.

As items are removed, the system builds a live, itemized bill in real time, adding each product with its price and updating the running total, so the customer is charged automatically with no scanning, no barcodes, and no cashier. It is a practical take on grab-and-go retail.

Key features

  • Real-time product detection from multiple in-fridge cameras
  • Recognises items and quantities as they are removed
  • Generates a live itemized bill with a running total
  • Enables grab-and-go checkout without barcodes or a cashier

TaskPilot AI Agent

An AI agent that turns a plain-language request or an uploaded document into a finished result. It understands the task, plans the steps, picks the right tools, and runs them to reach an answer.

Overview

TaskPilot is an AI agent that takes a plain-language request, or an uploaded document, and works through it from start to finish. It first understands what kind of task it is, then plans the steps, decides which tools it needs, runs them, and returns a final answer.

Under the hood it connects an LLM to a set of tools: a calculator, web search, a file reader, and reminders. Each step is streamed to a live console so you can follow its reasoning, and it is built as a full web app with a task composer, a history of past runs, and a tools panel.

Key features

  • Understands a task from plain language or a document
  • Plans and breaks the work into steps automatically
  • Runs tools such as a calculator, web search, file reader, and reminders
  • Streams each step to a live console and returns a final answer

Football Object Detection System

A custom YOLOv8 model that detects the ball and the goalpost in football frames, drawing bounding boxes with confidence scores.

Overview

This is the object-detection model at the core of my football work. I trained a custom YOLOv8 model to recognise the ball and the goalpost in football frames, and it draws a bounding box with a confidence score around each one it finds.
